## 📖 文档说明

### UI 原型设计规范

本文档详细描述了 SpeakSense 应用的界面设计规范，包括：

- **设计系统**: 色彩、排版、间距、圆角、阴影等基础设计元素
- **核心页面**: 首页、题板详情、练习页、评估页、生词本页的布局结构
- **交互设计**: 动画过渡、加载状态、错误处理等交互细节
- **响应式设计**: 移动端、平板、桌面的适配方案
- **无障碍设计**: 对比度、触控、屏幕阅读器支持

适用人群：UI/UX 设计师、前端开发、产品经理
