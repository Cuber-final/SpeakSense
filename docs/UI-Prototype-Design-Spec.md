## 1. 产品定位与目标

### 1.1 产品定位
- **核心理念**: AI 驱动的英语口语教练，帮助用户通过情景对话练习提升口语能力
- **目标用户**: 英语学习者（A1-C1 级别），主要使用中文母语环境
- **使用场景**: 碎片化时间练习（5-15分钟/次），桌面端沉浸学习

### 1.2 设计原则
| 原则 | 说明 |
|------|------|
| **简洁优先** | 减少认知负担，聚焦核心任务 |
| **即时反馈** | 每个操作都有明确的视觉反馈 |
| **游戏化激励** | 进度条、成就系统、可视化成长 |
| **情感化设计** | 友好的文案、鼓励性的反馈 |

## 2. 信息架构

### 2.1 核心功能模块

```
┌─────────────────────────────────────────────────────────────┐
│                      底部导航栏（4个Tab）                     │
├──────────┬──────────┬──────────┬───────────────────────────┤
│  首页   │  练习   │  评估   │        生词本             │
│ (Boards)│(Practice)│(Evaluation)│    (Wordbook)          │
└──────────┴──────────┴──────────┴───────────────────────────┘
    │          │           │                │
    ▼          ▼           ▼                ▼
  题板列表    练习界面    评估汇总         生词列表
    │          │           │                │
    └─▶ 题板详情页        │          生词详情/编辑
         (问题预览)        │

**主流程**: 浏览题板 → 查看详情 → 开始练习 → 答题（文本/语音）→ 提交 → 查看评估 → 收集生词

**分支流程**:
- 生词收集 → 查看生词本 → 标记掌握
- 历史评估回顾 → 评估详情页

## 3. 设计系统

### 3.1 色彩系统

| 用途 | 色值 | 用途说明 |
|------|------|----------|
| **主色调** | `#2962FF` | 品牌 Blue，用于主要按钮、高亮 |
| **次要色** | `#6C5CE7` | 辅助色，用于标签、徽章 |
| **成功色** | `#00C853` | 完成任务、正确答案 |
| **警告色** | `#FFAB00` | 提醒、35词软上限 |
| **错误色** | `#FF5252` | 错误、删除操作 |
| **中性灰** | `#F5F5F5` ~ `#212121` | 背景、边框、文字 |

**明暗主题映射**:
```
Light Mode: 背景 #FFFFFF, 文字 #212121, 次要文字 #757575
Dark Mode: 背景 #121212, 文字 #FFFFFF, 次要文字 #B0B0B0
```

### 3.2 排版系统

| 层级 | 字体大小 | 字重 | 用途 |
|------|----------|------|------|
| H1 | 28px | Bold | 页面标题 |
| H2 | 22px | SemiBold | 卡片标题 |
| H3 | 18px | Medium | 章节标题 |
| Body | 16px | Regular | 正文内容 |
| Caption | 14px | Regular | 辅助说明 |
| Small | 12px | Regular | 标签、时间戳 |

**字栈**:
- 中文: `Noto Sans SC`
- 英文/数字: `Inter`

### 3.3 间距系统（4pt Grid）

| Token | 值 | 用途 |
|-------|-----|------|
| gap4 | 4px | 标签间距 |
| gap8 | 8px | 小组件内间距 |
| gap12 | 12px | 卡片内边距 |
| gap16 | 16px | 页面边距、卡片间距 |
| gap24 | 24px | 大区块间距 |
| gap32 | 32px | 页面顶部/底部留白 |

### 3.4 圆角与触控

| 用途 | 圆角 | 触控尺寸 |
|------|------|----------|
| 按钮/卡片 | 12px | 44×44px (最小) |
| 输入框 | 8px | 44×44px (最小) |
| 标签/徽章 | 16px | N/A |

### 3.5 阴影系统

| 层级 | 阴影 | 用途 |
|------|------|------|
| Level 0 | none | 边框元素 |
| Level 1 | 0 1px 2px rgba(0,0,0,0.1) | 按钮、小卡片 |
| Level 2 | 0 4px 8px rgba(0,0,0,0.12) | 悬浮卡片 |
| Level 3 | 0 8px 16px rgba(0,0,0,0.15) | 模态框 |

├─────────────────────────────────────┤
│  ┌───────────────────────────────┐ │

│                                   │
│  ┌───────────────────────────────┐ │
│  │ 上下文: 你在繁忙的咖啡店...   │ │  ← 上下文提示
│  └───────────────────────────────┘ │
│                                   │
│  ┌───────────────────────────────┐ │
│  │ 输入你的回答（英语）         │ │  ← 文本输入框
│  │ [─────────────────────────]   │ │     FTextField
│  │ 字数: 12/40                 │ │     实时计数
│  └───────────────────────────────┘ │
│                                   │
│  ┌───────────────────────────────┐ │
│  │ [🎤 开始录音]                │ │  ← 语音按钮
│  │ 录音时间: 0/90秒             │ │     倒计时
│  └───────────────────────────────┘ │
│                                   │
│  [保存草稿]           [提交答案]   │  ← 底部按钮组
└─────────────────────────────────────┘
```

**文本模式设计**:
- 输入框: 最大高度 120px，超过滚动
- 字数计数: 35 词以下绿色，35-40 橙色警告，>40 红色禁止提交
- 草稿保存: 自动保存到本地，下次打开恢复

**语音模式设计**:
```
录音中状态:
  ┌───────────────────────────────┐
  │  ● 录音中... 0:45/1:30     │  ← 波形动画
  │                              │
  │  [停止]  [取消]             │
  └───────────────────────────────┘

预览编辑状态:
  ┌───────────────────────────────┐
  │ ASR 识别结果:                │
  │ "I'd like a small latte..."  │  ← 可编辑文本框
  │                              │
  │ [重新录音]  [确认提交]       │
  └───────────────────────────────┘
```

**进度指示**:
- 顶部显示 "Q1/10"
- 进度条: 横向或垂直（根据设备方向）

## 5. 交互设计细节

### 5.1 动画与过渡

| 交互 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 页面切换 | 300ms | easeInOut | 标准推入/推出 |
| 底部导航切换 | 200ms | easeOut | 快速响应 |
| 按钮点击 | 120ms | easeOut | 触感反馈 |
| 卡片展开/折叠 | 250ms | easeInOut | 平滑过渡 |
| 加载动画 | 1s 循环 | linear | 骨架屏脉冲 |
| Toast 显示 | 200ms 入场 | easeOut | 从底部滑入 |

### 5.2 加载状态

**全局加载**:
```
┌─────────────────────────────────────┐
│         ⏳ 加载中...            │  ← 居中加载指示器
└─────────────────────────────────────┘
```

**分块加载**:
- 列表页: 骨架屏占位
- 卡片详情: shimmer 效果

**空状态**:
- 图标 + 标题 + 描述 + CTA 按钮

### 5.3 错误处理

**网络错误**:
```
┌─────────────────────────────────────┐
│         ❌ 网络错误              │
│  请检查网络连接后重试             │
│         [重试]                   │
└─────────────────────────────────────┘
```

**服务器错误**:
- 显示错误码 + 简化错误信息
- 提供反馈入口（邮件）

## 6. 响应式设计

### 6.1 断点定义

| 设备类型 | 屏幕宽度 | 布局调整 |
|----------|----------|----------|
| Mobile | < 600px | 单列、底部导航 |
| Tablet | 600-960px | 2列卡片、侧边栏导航 |
| Desktop | > 960px | 3-4列卡片、顶部导航 |

### 6.2 桌面端适配

**导航**:
- 底部导航 → 侧边栏（左侧 240px）
- 支持收起/展开（图标模式）

**卡片布局**:
- 移动端: 2列网格
- 桌面端: 3-4列网格
- 悬停效果: 阴影加深 + 边框高亮

**字体缩放**:
- 支持系统字体缩放（100%-200%）
- 最小可读性: 12px

## 7. 无障碍设计

### 7.1 对比度

- 正常文本: ≥ 4.5:1
- 大号文本 (≥ 18px): ≥ 3:1
- 交互元素: ≥ 3:1

### 7.2 触控与焦点

- 最小触控目标: 44×44px
- 键盘导航支持: Tab / 箭头
- 焦点指示器: 2px 蓝色边框

### 7.3 屏幕阅读器

- 所有按钮添加语义标签
- 图标添加 `label` 属性
- 状态变化播报（如"评估完成"）

## 9. 实施建议

### 9.1 设计阶段（建议1-2周）

**Week 1: 设计系统搭建**
- Day 1-2: 色彩、排版、间距规范
- Day 3-4: 核心组件设计（按钮、卡片、输入框）
