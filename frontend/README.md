# SpeakSense Flutter App

Flutter 客户端工程（Web / Android / iOS）。

## 本地开发

```bash
flutter pub get
flutter run -d chrome --no-web-resources-cdn
```

## 常用命令

```bash
flutter analyze
flutter test -r compact
dart format .
```

## 配置说明

- API 基础地址配置：`frontend/lib/app/env.dart`
- 开发态可通过应用内开发者菜单切换 Mock/API 数据源
